# 音影寻光 · 视觉升级（暗金风格）

目标：把所有界面尽可能向“暗金豪华”视觉靠拢，主张以大幅图片/背景、暗色基底与暖金色强调构建沉浸式界面，同时保持无障碍可读性与性能可控。

## 快速指引（要点）
- 基调：深色（接近 #0B0A09）背景 + 暖金色（建议主金 #C89B3B / 强金 #F0C869） + 深棕/暗灰作辅助。
- 关键视觉手段：大幅背景图片（艺术插画或摄影）、玻璃/磨砂卡片、微发光金边、精致图标与金属质感按键。
- 文本与可访问性：保证文本对比度（WCAG AA 最低），重要文本用白色或接近白色，次要文本用浅金或浅灰。

## 颜色与贴图
- 背景色（深）：#0B0A09
- 主金色（强调）：#C89B3B
- 强金高光：#F0C869
- 暗灰/棕（卡片基底）：#191414
- 文本主色：#FFFFFF
- 文本次色：#D9C79A
- 透明磨砂（玻璃层）：白色 8%~12% 叠加模糊

使用建议：把图片作为页面整体背景或模块背景（非局部小图）；在图片上覆以暗色蒙版以保证文本可读性（建议蒙版为黑色 40%~65%）。

## 版面与构图
- 首页/主界面以纵向分层布局为主：顶部保留品牌与设置/退出按钮，中间为大圆形或焦点区域（可用图片 + 金色边框），底部为卡片式导航（社区、商店）。
- 卡片尺寸：宽度靠近屏幕宽度的 86%~92%，圆角建议 22dp~28dp。
- 使用大量留白与中心对齐的视觉焦点，使用户注意力聚焦于中央圆盘或主要 CTA。

## 图片与素材规范
- 背景图：建议 4:3 或 9:16 的高质量图片，分辨率至少为设备最大分辨率的 1.5x；尽量使用暗调或可加暗色蒙版的素材。
- 图标与装饰：使用金属质感矢量图（SVG / Android VectorDrawable），并在边缘添加微弱金色描边或内发光。
- 资源位置：把大图放在 `app/src/main/res/drawable-nodpi/` 或 `app/src/main/assets/`，小图标使用矢量 drawable。

## 组件样式（Compose 实现建议）
- 全局 Theme：在 `ClientTheme` 中添加 `DarkGoldTheme` 模式分支，提供 `colors`, `shapes`, `typography`。
- 背景容器：`ImageBackground(modifier, imageRes, content)` 组件，内部自动应用暗色蒙版与安全区内边距。
- 卡片：`GoldCard`（支持磨砂、微模糊、金色描边、阴影）
- 按钮：圆形/大按钮使用金色边框与中心暗色填充，点击时使用微弱的金色发光动效（禁用强烈颜色变化以免刺眼）。
- 文本：标题用 Serif 或 SemiBold，字号放大（首页标题 34~42sp），副标题使用较细的灰金色。

## 可访问性与性能
- 对比度：保证主文本与背景对比度 >= 4.5:1（WCAG AA），若图片背景导致对比不足必须加深蒙版。
- 可缩放文本：确保所有文本对系统字体缩放友好（不裁剪）。
- 图片性能：大图使用 `drawable-nodpi` 并在加载时使用合适的缩放/压缩；避免在 UI 主线程解码超大图片。

## 动效与交互
- 轻量动效：按钮悬浮、金色高光移动、背景星光微动；时长控制在 120~220ms。
- 语音反馈：复用 `TtsAlertManager`，在重要交互（如开始导航、商品推荐）配合短促音效。

## 开发注意事项
- 保留 `Neumorphism` 组件作为备选，但主风格切换到 `DarkGoldTheme`：不要在同一界面混用两种强烈风格。
- 优先用 Compose 组件封装样式：`ImageBackground`, `GoldCard`, `GoldButton`, `AgentDecisionBanner`。
- 资源命名建议：`bg_home.jpg`, `ic_gold_shop.xml`, `bg_card_texture_1.png`。

## 示例判断（验收要点）
- 页面是否以大图为背景、并有暗色蒙版以保证文本可读？
- 交互控件是否使用金色强调且不过度闪烁？
- 重要文本（标题/CTA）在所有设备上是否可读且未被图片遮挡？
